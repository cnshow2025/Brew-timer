# 手沖咖啡計時器

單檔 HTML 的手沖計時工具，不依賴任何外部函式庫，可直接用瀏覽器開啟。

- 沙漏版：`index.html` → https://cnshow2025.github.io/Brew-timer/
- 水壺版：`kettle/index.html` → https://cnshow2025.github.io/Brew-timer/kettle/

## 功能

- 每段拆成「注水／等待」兩個子段，兩種沙／咖啡液顏色分層呈現
- 前置設定：粉重（14–22 g）、粉水比（1:12–1:20），自動換算總水量
- 四種沖法：三段式、四六法（粕谷哲）、Hoffmann 極致 V60、三刀流，另有自訂模式
- 每段顯示要注到的累計克數，可對照電子秤
- 大字倒數、本段剩餘、全程累計計時
- 注水轉等待單聲、段落切換兩聲、結束三聲，並伴隨震動
- 設定存於 localStorage，計時中申請螢幕常亮
