# 手沖咖啡計時器

單檔 HTML 的手沖計時工具，不依賴任何外部函式庫，可直接用瀏覽器開啟。

網址：https://cnshow2025.github.io/Brew-timer/

## 功能

- 左側為水壺 → 濾杯 → 分享壺的單一場景，注水時水壺傾倒繞圈、分享壺液面隨累計水量上升
- 右側為段落清單，顯示各段狀態與剩餘秒數，進行中的子段放大倒數，完成的段落自動收起
- 前置設定：粉重（14–22 g）、粉水比（1:12–1:20），自動換算總水量與全程時間
- 四種沖法：三段式、四六法（粕谷哲）、Hoffmann 極致 V60、三刀流，另有自訂模式
- 每段顯示要注到的累計克數，可對照電子秤
- 注水期間播放水滴聲（可關閉），注水轉等待單聲、段落切換兩聲、結束三聲，並伴隨震動
- 設定存於 localStorage，計時中申請螢幕常亮，空白鍵可開始／暫停
